# Learning goals and evidence

Each reading is a 20–30 minute start, followed by a concrete exercise. Links are in SOURCES.md. The mentor asks each student to demonstrate the learning goal, not just show a completed file.

| Week | Read | Practice | Learning goal | Evidence |
|---|---|---|---|---|
| 1 | Official IU box-score layout in SOURCES.md | Read one box score aloud; identify team vs player grain. | Acquire and clean sports data | Source-to-row audit and validated joins |
| 2 | METHODS.md: metric definitions | Derive eFG and possessions on a whiteboard; contrast pace and efficiency. | Design meaningful KPIs | Five hand-reconciled metrics and EDA captions |
| 3 | METHODS.md: inference paragraph | Resample five game cards manually, then run a bootstrap. | Apply statistical analysis | Claim, independent unit, interval and confounding note |
| 4 | DELIVERY.md: BI relationships and measures | Build one view from tidy exports and test a filter. | Create interactive visual analytics | Working workbook plus two usability reviews |
| 5 | REVIEW.md and RELEASE.md | Explain one basketball conclusion without using code. | Communicate and reproduce | Live demo, clean rerun and individual explanation |

Across all five weeks: each student authors one small reviewed PR weekly, reviews the preceding seat’s work, records meaningful assistant use, and can rerun another student’s notebook. In Week 4, each team executes one real cluster job if access is available and explains its CPU/memory choice. An unavailable allocation must be reported, never disguised.
